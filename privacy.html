StatPlay› プライバシーポリシー

StatPlay（以下「本サイト」）における、利用者の情報の取り扱いについて、以下のとおり定めます。

最終更新日：2026年5月30日

// 1. 運営者

本サイトは Sasai Lab（笹井淳平）が個人活動として運営しています。所属企業を代表するものではありません。

// 2. 取得する情報と利用目的

(1) 言語設定（機能Cookie・ローカルストレージ）

表示言語（日本語／英語）の選択を保持するため、Cookie sp_lang とブラウザのローカルストレージ sp:lang に選択内容を保存します。これは利用者の利便性のための機能的なもので、個人を特定する情報は含みません。

(2) アクセス解析（Google Analytics 4）

本サイトの利用状況を把握し、コンテンツを改善する目的で、Google LLC が提供する Google Analytics 4 を利用しています。Google Analytics は Cookie（_ga 等）を用いて、以下のような情報を統計データとして収集します。

  • 閲覧されたページや滞在状況などの行動データ
  • 参照元（どのサイト・検索から来たか）
  • ブラウザ・OS・デバイスの種類、画面サイズ、言語設定
  • おおよその地域（IPアドレスから推定。Google Analytics 4 では IPアドレス自体は記録・保存されません）

これらは統計的に集計され、特定の個人を識別する目的では利用しません。

// 3. 外部送信される情報（第三者提供）

本サイトの利用にあたり、以下の外部サービスへ利用者の情報（アクセス情報・IPアドレス・利用環境など）が送信されます。各社における取り扱いは、それぞれのプライバシーポリシーをご確認ください。

Google Analytics（Google LLC）

送信内容：Cookie・アクセス情報／利用目的：アクセス解析
Google プライバシーポリシー ↗

jsDelivr CDN（数式表示ライブラリ KaTeX の配信）

本サイトは数式を表示するためのライブラリ KaTeX を CDN（cdn.jsdelivr.net）から読み込みます。これに伴い、利用者のIPアドレス・ブラウザ情報が CDN 提供元に送信されます。
jsDelivr プライバシーポリシー ↗

// 4. Cookie の管理・無効化

利用者はブラウザの設定により Cookie を拒否・削除できます。Cookie を無効にしても本サイトの主要な機能は利用できますが、言語設定が保持されない場合があります。

Google Analytics による収集を無効にしたい場合は、Google が提供する Google アナリティクス オプトアウト アドオン ↗ をご利用ください。

// 5. データの保存期間

機能 Cookie sp_lang の有効期限は最長2年です。Google Analytics が設定する Cookie の有効期限およびデータの保持期間は、Google の仕様に従います。

// 6. 外部リンクについて

本サイトには外部サイトへのリンクが含まれます。リンク先サイトにおける情報の取り扱いについて本サイトは責任を負いません。各サイトのプライバシーポリシーをご確認ください。

// 7. 開示等のご請求・お問い合わせ

本ポリシーに関するご質問、または取得情報の開示・訂正・削除等のご請求は、GitHub の Issue よりお問い合わせください。
